<details>
<summary><b>⚡ High-Speed BLDC Motor Drive Using Custom H-Bridge Circuit</b></summary>
<br>

Designed and implemented a custom H-Bridge-based BLDC motor drive system as an alternative to conventional ESC-based control approaches.

| Category | Details |
| :--- | :--- |
| **Stack** | Discrete H-Bridge circuit, MOSFET switching, transistor gate-drive design |
| **Scale** | Custom circuit-level design, no commercial ESC used |
| **Performance** | Exceeded the measurable range of the available tachometer (>9999 RPM) |
| **Security** | Dead-time management and shoot-through condition mitigation |
| **Impact** | Sparked faculty discussion on transistor drive design and switching efficiency |
| **Repository** | `github.com/S-Abrar-Hussain/bldc-hbridge-drive` |

Through extensive experimentation with transistor biasing, gate-drive optimization, and switching timing, the design achieved exceptionally high motor speeds. A key innovation was the strategic resistor selection in the transistor driving stage — a low-value base resistor paired with a higher collector resistor — improving switching behavior and reducing timing-related issues.

</details>
